# 115 STRM

把 **115 网盘**的目录结构镜像成本地 `.strm` 文件树，给支持 `.strm` 的播放器（Emby / Jellyfin / Kodi / Infuse / VidHub…）扫描播放 —— **内外网同址、直连 115 CDN、不占 NAS 带宽**，自带网页界面。

> ⚠️ **播放器必须支持 `.strm`**。VidHub 会把 strm **末尾的换行**当成地址的一部分 ⇒ 加载失败；本工具生成的 strm **不带换行**（旧文件需自行去掉）。

## 使用方法

**① 起容器**

```bash
docker run -d --name 115strm -p 8767:8767 \
  -e ACCESS_TOKEN='换成一个够长的口令' \
  -v /path/to/data:/data -v /path/to/strm:/out \
  --restart unless-stopped xinxinenjoy/115strm:latest
```

compose：

```yaml
services:
  115strm:
    image: xinxinenjoy/115strm:latest
    container_name: 115strm
    restart: unless-stopped
    ports: ["8767:8767"]
    environment: [ACCESS_TOKEN=换成一个够长的口令]
    volumes:
      - ./data:/data     # 参数 / 账号 / 目录树 / 回执
      - ./strm:/out      # ★ 生成的 strm 树
```

打开 `http://<你的主机>:8767` —— 设置页顶部有「**还差 N 步就能跑**」清单，跟着走即可。

**② 登录 115** —— 「设置 › 115 账号」→ **扫码登录**（推荐）或贴 cookie。

**③ 填播放地址** —— 「设置 › 播放地址」填 **strm 内容前缀**（**出厂为空、必填**），点**「自检」**确认真能播。**空着不动手。**

**④ 配范围 + 先预览** —— 「设置 › 同步范围」填同步根、勾子目录（没跑过会提示先去跑一轮）→ 「同步」页先点**「预览差异」**（零请求、不落盘）看清会做什么 → 再点「立即执行」。

## 功能

- **自己跟上网盘**：调 115 的「导出目录树」拿全盘结构再对账，**不用手导 txt**
- **只处理你指定的目录**：网页上勾选，**留空 = 全部**
- **账号管理**：扫码 / 贴 cookie，可多账号、校验、切换、删除
- **结构镜像**：目录层级原样落地，**只建真有片子的目录**
- **删除二次确认**：文件消失先挂起 → 等 N 分钟 → 再扫确认 → 才删；一轮消失比例超阈值则一条都不删
- **内容没变不重写**：保住 mtime，媒体库不会每次全量重扫
- **外挂字幕随行下载**（默认关，网页「设置 › 字幕」开）：把网盘上已有的字幕**真下载**到 strm 旁边，播放器才看得见
- **定时扫描**：填 5 段 cron（`0 6 * * *` = 每天 06:00），下面**当场显示「下次运行」**；留空 = 不跑。只认 `*` / 数字 / `*/N`，**天级**节奏
- **结果看得清**：分块展示（概览 / 目录 / 视频 / 字幕 / 请求耗时），点数字展开**每一次请求** —— 接口 · 在干什么 · 耗时 · 节流等待

## 注意要点

- 🔴 **strm 内容前缀在网页「设置 › 播放地址」里填，不是环境变量** —— 写进 `.env` / compose **不生效**。
- 🔴 **前缀要写到 Alist 挂载点的完整路径**，末段与「同步根」一致；少写一层会回 `storage not found`，**而状态码仍是 200**，肉眼看不出来 ⇒ **务必点「自检」**。
- 🔴 **`/data` 要挂到宿主机**（参数 · 账号 · 目录树 · 回执）；**`/out` 也要映射出去**给播放器扫。
- 🔴 **`ACCESS_TOKEN` 映射到公网务必设长**，并建议走 HTTPS（反代 + 证书）。
- ⚠️ **`REMOTE_ROOT` / `INCLUDE_DIRS` 写进环境变量会盖住网页上的修改** ⇒ 一般在网页上选。
- ⚠️ **外挂字幕**：`.strm` 只有一行地址 ⇒ 字幕**必须落到本地**，命名固定 **`视频全名 + [语言尾] + 字幕扩展名`**（`影片.mkv.srt`）—— `影片.srt` / `影片.mkv.strm.srt` 播放器**都不认**。**配不上一律不下**（配错比没配更糟），只在回执里列。⛔ 网盘上没有的工具造不出来。
- ⚠️ **想跟同仓库的 `115offline` 共用登录态**：设 `ACCOUNTS_FILE=/shared/accounts.json`，把那目录挂成 `/shared`。⛔ **必须挂目录、不能只挂单文件**（写入是 tmp+rename；单文件 bind-mount 会报 `busy`）
- ⚠️ **安全边界**：删除有双重保险（必须 `.strm`、必须落在输出目录内）+ 二次确认，**不碰非 strm 文件**。⚠️ **无「只演练」开关**，先看再动用「预览差异」。为拿全盘结构会做两下**写操作**：`POST /files/export_dir`（在你盘上生成临时件）与 `POST /rb/delete`（删它，走 **115 回收站**、非永久，`--keep` 可留）。其余全是只读接口。

## 环境变量

业务参数（前缀 / 节流 / 删除判定 / 扩展名 / 字幕…）在网页**设置**页管，存 `data/config.json`、改完生效；**下面这些引导项也可走环境变量**。

| 变量 | 默认 | 说明 |
|:---|:---|:---|
| `ACCESS_TOKEN` | 空 | 网页口令。留空 = 不校验（仅限内网）；映射公网必须设 |
| `PORT` | `8767` | 网页监听端口（容器内） |
| `DATA_DIR` / `OUTPUT_DIR` | `/data` / `/out` | 数据目录 / ★ strm 树落点 |
| `ACCOUNTS_FILE` | `DATA_DIR/accounts.json` | 账号文件 |
| `ACCOUNT_ID` | 空 | 用哪个账号（**账号 id**，非名字）；留空 = 第一个能用的 |
| `P115_COOKIE` | 空 | 直接贴 cookie，优先级最高。调试用 |
| `REMOTE_ROOT` / `INCLUDE_DIRS` / `SCHEDULE_CRON` | 空 | 同步根 / 只处理的子目录 / 定时 cron。**写了会盖住网页上的修改** |
| `SUBTITLE_ENABLE` / `SUBTITLE_SKIP_SUP` / `SUBTITLE_EXT` / `SUBTITLE_WORKERS` | `false` / `true` / 常见字幕扩展名 / `4` | 外挂字幕开关等（一般在网页改） |

## 命令行

网页是默认动作；命令行适合定时 / 无人值守 —— 容器内跑 `docker exec 115strm python -m app <命令>`：

`serve`（开网页，默认）· `sync`（跑一轮）· `preview`（只预览）· `export`（只导目录树）· `pending`（看挂起删除）· `apply --yes`（确认删除）· `doctor --check`（环境自检 + 前缀连通性）
