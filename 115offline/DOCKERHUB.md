# 115 离线推送

自托管的 **115 网盘离线下载推送工具**：在你自己机器上跑一个网页服务，手机粘磁力 / ed2k / HTTP 链接，
一键推给 115 离线下载。

**原理一句话**：本工具只做两件事 —— 用你的登录态调 115 官方的「离线下载」接口**把链接递进去**，
以及事后**整理网盘**。**真正的下载在 115 云端跑，你关机也不影响**。

## 使用方法

**① 起容器**

```bash
docker run -d --name 115offline \
  -p 8765:8765 \
  -e ACCESS_TOKEN=换成一个够长的口令 \
  -v /path/to/data:/data \
  --restart unless-stopped \
  xinxinenjoy/115offline:latest
```

等价的 compose：

```yaml
services:
  115offline:
    image: xinxinenjoy/115offline:latest
    container_name: 115offline
    restart: unless-stopped
    ports:
      - "8765:8765"
    environment:
      - ACCESS_TOKEN=换成一个够长的口令
      - TZ=Asia/Shanghai
    volumes:
      - ./data:/data
```

**② 打开网页、登录 115** —— 访问 `http://部署机器IP:8765`，首屏输入你设的 `ACCESS_TOKEN`；
进「账号管理」**扫码登录**（推荐选「电视端」，最不容易把正在用的登录挤掉），也可以手贴 cookie。

**③ 粘链接 → 推送** —— 「离线推送」页一次贴一大段都行：自动挑出链接、自动去重、
32 位磁力自动转 40 位、百家姓 / 佛曰等中文暗号直接还原；推送前可多级下探挑目标目录，也能设成该账号默认。

## 功能

- **推送**：多账号切换 · 批量粘贴 · 中文暗号还原 · 自动去重 · 选保存目录
- **任务**：本地推送记录（本工具发出去的每一笔都记账，含失败原因）· 离线任务按状态筛选 · 一键跳去整理
- **整理**：任意目录改名（`片名（年份）` / 分季）· 分集命名 · 批量改名 · 批量删除 · 回收站多选还原

## 注意要点

- 🔴 **`/data` 必须挂到宿主机** —— 里面是 115 登录态、目录缓存与推送记录；不挂 ⇒ 容器一重建全丢。
- 🔴 **端口一旦映射到公网 ⇒ `ACCESS_TOKEN` 务必设长**，并建议走 HTTPS（反向代理 + 证书）。
- ⚠️ **扫码 / cookie 登录 = 115 账号登录态**，只存在你自己的 `/data`，工具不向任何第三方发送。
- 容器内端口固定 **8765**，宿主机映射随意；建议设 `TZ`，否则任务时间看着不对。
- **批量改名 / 删除不并发**（115 接口明确要求「删除不要并发、删除与还原互斥」）⇒ 大目录操作偏慢，属正常。

## 环境变量

| 变量 | 默认 | 说明 |
|:---|:---|:---|
| `ACCESS_TOKEN` | 空 | 访问口令，**映射到公网务必设置** |
| `DATA_DIR` | `/data` | 数据目录（115 cookie · 目录缓存 · 推送记录），**必须挂到宿主机** |
| `FOLDER_CACHE_TTL` | `300` | 目录缓存有效秒数，`0` = 不过期只能手动刷新 |
| `TZ` | 容器系统 | 时区，如 `Asia/Shanghai` |

## 不想扫码？手抓 cookie

电脑浏览器登录 [115.com](https://115.com) → `F12` → **网络 / Network** → 刷新页面 →
点任意一个发往 `115.com` 的请求 → 请求头里的 `Cookie:` 整行复制（`UID=` `CID=` `SEID=` 三项必需）→
粘进「账号管理」。
